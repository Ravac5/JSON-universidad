## **ESPAÑOL**

En este JSON los autores se modelaron como un array de objetos, esto porque el libro tiene más de un autor y cada autor está compuesto por dos claves, un nombre y un país.
Los géneros son simplemente un array de strings, ya que estos no son un objeto compuesto por varias claves, simplemente son arrays de la clave géneros.

## **ENGLISH**

In this JSON "autores" is an array of objects. This is because the book can have more than one author and every author its composed of two keys, a name and a country.
The genres are simply an array of strings. They are not an object of many keys, simply an array of genres.

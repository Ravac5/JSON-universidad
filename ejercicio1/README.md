## **ESPAÑOL**
En este json encontramos varios errores, empezando por que la clave nombre se encuentra sin doble comillas y su valor string se encuentra con comillas simples en vez de dobles.
En el caso del booleano True, este está mal escrito y su forma correcta es true con “t” minúscula.
Dentro del array “tags” al final de este encontramos una trailing coma, lo cual no está permitido en JSON.
Por último en la clave “ultimaCompra” encontramos un valor que se debería almacenar como string y por ende llevar comillas dobles. También encontramos una coma al final de este valor, la cual es una trailing coma y por lo tanto no está permitido.
